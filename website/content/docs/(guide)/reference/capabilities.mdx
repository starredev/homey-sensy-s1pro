title: "Capabilities"

Capabilities are mapped by [`homey-esphomedriver`](/docs/developers/esphomedriver) from the sensor's entities,
using the app's brand profile. Device class: **sensor**.

## Always present

| Capability | Type | Title | Unit | Insights | Source entity |
|---|---|---|---|---|---|
| `alarm_presence` | boolean | Presence | | yes | `any_presence` |
| `alarm_motion` | boolean | Motion | | yes | `any_movement` |
| `sensy_people` | number (0–3) | People | | yes | `all_targets_count` |
| `measure_temperature` | number | Temperature | °C | yes | `bme688_temperature` |
| `measure_humidity` | number | Humidity | % | yes | `bme688_humidity` |
| `measure_pressure` | number | Pressure | mbar | yes | `bme688_pressure` |
| `measure_co2` | number | CO₂ | ppm | yes | `scd40_co__concentration` |
| `sensy_iaq` | number (0–500) | Air quality (IAQ) | | yes | `bme688_iaq` |
| `sensy_air_quality` | enum | Air quality | | no | `bme688_iaq_classification` |
| `sensy_iaq_accuracy` | enum | Air quality calibration | | no | `bme688_iaq_accuracy` |
| `measure_tvoc` | number | VOC | ppm | yes | `bme688_voc_equivalent` |
| `measure_luminance` | number | Luminance | lx | yes | `ltr390_ambient_light__lux_` |
| `measure_ultraviolet` | number | Ultraviolet | UV index | yes | `ltr390_uv_index` |

### Enum values

`sensy_air_quality`: `Excellent`, `Good`, `Lightly polluted`, `Moderately polluted`, `Heavily polluted`,
`Severely polluted`, `Extremely polluted`. The values are the firmware's own text, so they are also what the
*Air quality* token contains.

`sensy_iaq_accuracy`: `Stabilizing`, `Uncertain`, `Calibrating`, `Calibrated`.

## Per drawn zone

`N` is 1, 2 or 3. Present only for zones with an outline of at least three points.

| Capability | Type | Title | Insights | Source entity |
|---|---|---|---|---|
| `sensy_zone_presence.zoneN` | boolean | Zone N presence | yes | `zone_N_presence` |
| `sensy_zone_movement.zoneN` | boolean | Zone N movement | yes | `zone_N_movement` |
| `sensy_zone_people.zoneN` | number (0–3) | People in zone N | yes | `zone_N_target_count` |

## Maintenance actions

| Capability | Title | Presses |
|---|---|---|
| `button.calibrate_co2` | Calibrate CO₂ sensor | `scd40___forced_calibration` |
| `button.restart` | Restart sensor | `esp32___restart_module` |
| `button.restart_radar` | Restart radar | `radar___restart_module` |
| `button.refresh` | Refresh capabilities | *(rebuilds the capabilities)* |

## Optional

With **Show diagnostic capabilities** or **Show configuration capabilities** on, the library adds the remaining
diagnostic and configuration entities with its generic mapping: `alarm_connectivity`,
`measure_temperature.esp32___temperature`, `esphome_string.esp32___ip`, `esphome_string.esp32___ssid`,
`esphome_string.esp32___wifi_strength`, the LED (`onoff`, `dim`, `light_hue`, `light_saturation`,
`light_effect`) and switches such as `onoff.ble___proxy`, `onoff.mlt8530___buzzer` and
`onoff.radar___bluetooth`. Exact ids can differ slightly when several entities share a base capability.

## Custom capability definitions

The app defines these custom capabilities (in `.homeycompose/capabilities/`):

| Id | Type | Notes |
|---|---|---|
| `sensy_people` | number | 0–3, no decimals |
| `sensy_iaq` | number | 0–500, no decimals |
| `sensy_air_quality` | enum | See above |
| `sensy_iaq_accuracy` | enum | See above |
| `sensy_zone_presence` | boolean | Used as `sensy_zone_presence.zoneN` |
| `sensy_zone_movement` | boolean | Used as `sensy_zone_movement.zoneN` |
| `sensy_zone_people` | number | 0–3, used as `sensy_zone_people.zoneN` |
