# Documentation website

The source of [starredev.github.io/homey-sensy-s1pro](https://starredev.github.io/homey-sensy-s1pro/), built with
[Fumadocs](https://fumadocs.dev/) (Next.js, static export).

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static export to out/
```

See [This website](https://starredev.github.io/homey-sensy-s1pro/docs/developers/website/) for how pages are written
and published.
