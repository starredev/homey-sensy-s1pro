# Getting started

Four steps from an unboxed sensor to working flows:

1. **[Requirements](requirements.md)**: check your Homey, the sensor firmware and your network.
2. **[Installation](installation.md)**: install the app from the Homey App Store or with the Homey CLI.
3. **[Adding the sensor](pairing.md)**: let Homey find the sensor, or add it by IP address.
4. **[Placing the sensor](placement.md)**: mount it so the radar sees the room well and draws zones in the
   right place.

After that, continue with the [User guide](../guide/index.md).
